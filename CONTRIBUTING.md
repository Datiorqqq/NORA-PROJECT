# Правила розробки NORA для студентів

## Робота із задачами та Pull Request

1. **Одна задача → одна гілка → один Pull Request (PR).** Не змішуйте незалежні задачі. Прив'язуйте PR до відповідного Issue.
2. **Прямі push у `main` заборонені.** Відгалужуйтеся від актуального `main`; використовуйте `feat/<issue>-short-name`, `fix/<issue>-short-name` або `chore/<issue>-short-name`.
3. **У `main` зливаємо лише через Squash and merge.** Один прийнятий PR = один коміт. Не використовуйте Merge commit або Rebase and merge.
4. **Перед кожним push перевіряйте код локально:** `npm run lint`, `npm run format:check`, `npm run typecheck`, `npm test` і `npm run build`. Спочатку запустіть `npm install`.
5. **Нову функціональність супроводжуйте unit-тестами.** Перевіряйте успішні сценарії, помилки, порожні/некоректні значення та граничні випадки. Виправлення дефектів мають містити regression test.
6. **PR не зливаємо, поки CI не зелений і не виконані acceptance criteria.** Для змін інтерфейсу обов'язкова браузерна перевірка на desktop, mobile portrait і mobile landscape зі скриншотами. Якщо браузерні перевірки не виконані, PR залишається відкритим.
7. Перед merge потрібне code review. Автор PR не повинен обходити перевірки, навіть якщо локально все працює.
8. Не комітьте `.env`, токени, паролі, `node_modules/` та згенеровані артефакти. Для налаштувань використовуйте `.env.example`.

## Інструменти

- **ESLint:** `npm run lint` (для виправлень без зміни логіки — `npm run lint:fix`).
- **Prettier:** `npm run format:check` (форматування — `npm run format`).
- **Unit-тести:** `npm test`. Новий код без тестів не готовий до рев'ю.
- **TypeScript:** `npm run typecheck`.
- **Production build:** `npm run build`.

Якщо задача стосується незмердженої feature-гілки, тести додавайте у PR цієї функції або окремим PR, що таргетить цю feature-гілку. Не переносіть незмерджений код напряму у `main`.

## Контекст проєкту

Актуальна архітектура Nora — React Router v8 + Vite + TypeScript. Інтерфейс і серверні маршрути розміщуються в `app/`, конфігурація та інтеграції з секретами — у `app/.server/`.
