# NORA Frontend (React + Vite + Tailwind CSS)

Директорія клієнтської частини проєкту (зона відповідальності **Студента 4** у співпраці зі **Студентом 5 — UI/UX**).

## Вихідний дизайн-прототип
Актуальний інтерактивний прототип усіх екранів (Login, Registration, Dashboard, NORA AI Chat, Profile, UI Kit) знаходиться в репозиторії макета `Datiorqqq/NORA_AI` (`src/App.tsx` та `src/index.css`).

## Рекомендована структура

- `src/components/` — перевикористовувані кнопки, поля, бічне меню, картки
- `src/pages/` — сторінки Auth, Dashboard, AssistantChat, Profile
- `src/services/` — запити до Backend API
- `src/context/` — стан авторизації користувача
- `src/App.tsx` — налаштування React Router
