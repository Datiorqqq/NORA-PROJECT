# NORA — вихідні матеріали UI/UX

[Інтерактивний макет Figma Make](https://www.figma.com/make/ze8eCZzQdRYmApetTibYkG/NORA)

Дата знімка локального коду — 18 листопада 2026 року. Матеріали передають дизайн для задачі #13 та подальшої реалізації інтерфейсу в #3.

## Вміст

- `NoraApp.tsx` — композиція екранів і демонстраційні переходи.
- `nora/screens/` — вхід, реєстрація, огляд, курси, асистент і профіль.
- `nora/shared/` — елементи інтерфейсу, навігація, переклади та демонстраційні стани.
- `nora/data/` — демонстраційні курси, розклад і дедлайни.
- `styles.css` — точка входу CSS з імпортами десяти тематичних файлів у `styles/`.

У темній темі літера N має основу `#818CF8`, грань `#6366F1` і золотий компас. Екран входу використовує два розмиті світлові акценти. Для вузьких вертикальних екранів додано мінімальний верхній запас 48 px під камеру, для коротких горизонтальних — бічний запас із підтримкою системних safe-area значень.

## Використання у застосунку

Це вихідний код React-прототипу з Figma Make. Основний застосунок команди працює на React Router Framework Mode. Для інтеграції перенесіть потрібні компоненти до `app/`, підключіть стилі через чинний механізм застосунку й замініть демонстраційні переходи на погоджені маршрути React Router.

CSS імпортує Google Fonts і Tailwind CSS. Під час інтеграції потрібно узгодити ці залежності з основним застосунком. Файли Next.js, Payload, платформні конфігурації та секрети до цього знімка не включені.

## Межі прототипу

Курси, відповіді AI, оцінки та розклад — демонстраційні. Вхід і реєстрація змінюють стан прототипу, реальної авторизації та підключення Moodle немає. Перед використанням у робочому застосунку потрібні серверна авторизація та реальні джерела даних.

## Перевірка й передача

Світлу й темну палітри логотипа раніше переглянуто у Figma Make. Повну браузерну перевірку останніх відступів під камеру на дашборді у portrait і landscape ще потрібно завершити та додати актуальні скриншоти до PR.

Матеріали в цій папці не підключені до маршрутів основного застосунку. Acceptance criteria інтеграції інтерфейсу й Moodle перевіряються у відповідних задачах.
