# Документація Nora

Ця директорія призначена для актуальних технічних матеріалів і результатів роботи команди:

- Контракти маршрутів React Router (`loader/action`) та серверних інтеграцій Moodle/Gemini.
- Документація доступу до персональних Moodle-даних, обмежень API та обробки помилок.
- Сценарії acceptance/E2E-перевірок, usability-тестування та підтверджені результати.

Для запуску проєкту, архітектури й правил розробки спочатку прочитайте [кореневий README](../README.md) та [CONTRIBUTING.md](../CONTRIBUTING.md).

Нереалізовані можливості не документуйте як готові; плани та критерії приймання ведуться в [GitHub Issues](https://github.com/Datiorqqq/NORA-PROJECT/issues).
