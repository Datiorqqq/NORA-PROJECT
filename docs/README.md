# Документація та База Знань NORA PROJECT

Ця папка містить спільні матеріали команди:
- Специфікації ендпоінтів REST API та моделей даних Firestore.
- Структуровані дані університету для контексту ШІ (розклад, факультети, стипендії, гуртожитки, FAQ).
- Сценарії та результати Usability-тестування інтерфейсу (Студент 5 — UI/UX).
